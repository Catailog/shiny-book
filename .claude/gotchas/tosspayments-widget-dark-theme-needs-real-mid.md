# 토스페이먼츠 결제위젯 다크 테마는 테스트 환경에서 불가능

결제위젯(`@tosspayments/tosspayments-sdk`의 `widgets()`)의 UI 색상/디자인은 코드에서 `theme` 같은 옵션으로 바꿀 수 없고, 토스페이먼츠 "결제위젯 어드민" 대시보드에서 `variantKey`별로 미리 디자인해둔 버전을 코드에서 골라 쓰는 구조다. 그런데 실제로 그 어드민에 로그인해보면 다음 메시지로 막힌다.

```
결제위젯을 바로 쓸 수 있는 상점아이디(MID)가 없어요
결제위젯 사용 불가 MID 안내
- 호스팅 이용 (카페24 / 아임웹 / 고도몰 / 가비아 / 위사 등)
- 링크페이 이용
- 포트원(아임포트) 이용
- 빌링(정기결제/자동결제) 이용
```

즉 결제위젯을 실제로 쓸 수 있는 MID는 토스페이먼츠와 직접 전자결제 계약을 맺어야 발급되고, 테스트/샌드박스 키만으로는 이 어드민 자체에 진입할 수 없다. 순수 개발 단계에서는 위젯 색상 커스터마이징이 원천적으로 불가능하다.

## API 키 종류 확인

결제위젯 SDK(`widgets()`)를 쓴다면 "결제위젯 연동 키"(클라이언트 키에 `gck`, 시크릿 키에 `gsk`가 들어감)를 써야 한다. "API 개별 연동 키"(`ck`/`sk`)는 결제창·브랜드페이 SDK 전용이라 이 프로젝트 구조에서는 필요 없다. 키 종류를 잘못 짝지어 쓰면 `INVALID_API_KEY` 에러가 난다.

## 해결

위젯 내부를 다크로 바꾸는 대신, 위젯을 감싸는 컨테이너에 테마와 무관하게 항상 밝은 고정 배경(`--surface-light` 토큰)을 입혀서 "의도적으로 놓인 밝은 결제 패널"처럼 보이게 처리한다. `src/app/checkout/[orderId]/checkout-widget.tsx` 참고. 체크아웃 페이지의 테스트 안내 문구에도 이 한계를 명시해뒀다(`t.checkout.testNotice.darkThemeNote`).
